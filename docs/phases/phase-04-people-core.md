# Phase 4 — People core and self-service

**Status:** Not started · **Depends on:** Phase 3 · **Detailed before the phase starts, with your approval**

## Goal

Every employee and intern has a complete profile they can view and keep up to date, and HR has one trusted record per person.

## Scope

- [ ] Full employee profiles: personal, job, emergency contacts, bank (encrypted), statutory IDs (PAN; Aadhaar last 4 digits only)
- [ ] Document vault per person: ID proofs, certificates, issued letters; retention dates
- [ ] Org chart and directory, with field visibility per role
- [ ] Profile change requests through the workflow engine (employee proposes, HR approves)
- [ ] Privacy notice acknowledgement per notice version (DPDP)
- [ ] Self-service: view my data, request corrections, download my documents
- [ ] Personal data inventory and retention flags (DPDP readiness, full obligations from 13 May 2027)

## Reuses

Workflow engine (Phase 2), files, audit, custom fields (Phase 3), notifications.

## Exit criteria

1. Every Flourisense employee can sign in, see their profile and documents, and request a correction that HR approves.
2. Every person has acknowledged the current privacy notice.
