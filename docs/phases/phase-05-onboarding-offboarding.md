# Phase 5 — Onboarding and offboarding

**Status:** Not started · **Depends on:** Phase 4 · **Detailed before the phase starts, with your approval**

## Goal

Joining and leaving run as configurable checklists, with every letter generated and signed through the Phase 2 engine.

## Scope

- [ ] Offer-to-joining checklist templates per entity and role: documents to collect, tasks for HR, IT and the manager
- [ ] Candidate pre-joining portal: upload documents, fill details, accept policies (OTP)
- [ ] Appointment letters (a Labour Code requirement), signed with DSC
- [ ] Intern-to-employee conversion: a new engagement for the same person, keeping their history
- [ ] Asset handover and return
- [ ] Exit: resignation, notice period, clearance tasks per department, full-and-final trigger (for payroll)
- [ ] Relieving and experience letters for employees

## Reuses

Workflow engine, document engine and signing, people core, notifications.

## Exit criteria

1. A new joiner completes pre-joining online and receives a DSC-signed appointment letter.
2. A leaver completes clearance and receives signed relieving and experience letters.
