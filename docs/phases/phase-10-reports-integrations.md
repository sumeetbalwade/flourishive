# Phase 10 — Reports and integrations

**Status:** Not started · **Depends on:** Phases 4–8 · **Detailed before the phase starts, with your approval**

## Goal

Decision-ready HR dashboards for each tenant and ready-made connections to the tools customers already use. The API and webhook framework itself ships in Phase 3.

## Scope

- [ ] HR dashboards: headcount, joiners and leavers, attrition, leave, attendance, payroll cost
- [ ] Statutory and compliance reports; scheduled report emails
- [ ] Export to accounting software
- [ ] Slack and Microsoft Teams notifications
- [ ] Google Workspace and Microsoft 365 user provisioning
- [ ] Background verification vendor adapters
- [ ] Partner integrations through the public API and webhooks

## Exit criteria

1. Flourisense leadership uses the dashboards monthly.
2. At least one external system is integrated through the public API in production.
